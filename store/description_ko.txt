[제목]
zz심박수+ - 심박수, 심박존, 존별 시간, 운동 형태

[소개글]
현재 심박수와 심박존을 크게 표시하고, 기록하는 동안 존별 시간 비율을 히스토그램으로 보여주는 데이터 필드입니다.
넓고 높은 칸에서는 지금까지의 심박 분포를 분석해 어떤 형태의 운동인지(운동 형태, TID)를 함께 표시합니다.
가독성 향상을 위해 TitilliumWeb 폰트를 사용하여 제작되었습니다.
기존 zz심박수그래프를 새로 만든 앱입니다.

- 심박계(가슴 스트랩 또는 광학 심박)가 필요합니다. 휴대폰 연결은 필요 없습니다.

[심박수와 심박존]
- 현재 심박수를 칸을 꽉 채우는 큰 숫자로 표시합니다.
- 하트 옆에 현재 심박존을 존 색으로 표시합니다. 2.4처럼 존 안의 위치까지 소수로 보거나 정수로 볼 수 있습니다. (설정)
- 오른쪽 위에 평균, 최대, 랩 평균 심박 중 하나를 함께 표시합니다. (없음 선택 가능)
- 맨 아래 존 색 띠 위의 화살표가 지금 심박의 위치를 가리킵니다.

[존별 시간 히스토그램]
- 타이머가 도는 동안의 시간을 존별로 모아, 전체 기록 시간 중 각 존이 차지하는 비율(%)을 막대로 표시합니다.
- 일시정지와 자동 일시정지 시간은 빠집니다.
- 넓고 높은 칸에서는 막대 위에 비율(%)을 숫자로 표시합니다.
- 막대 모양은 줄무늬(숫자가 잘 보임) 또는 채움 중에서 고를 수 있습니다.
- 라이딩 중에 앱이 다시 켜져도 기록이 이어집니다.

[운동 형태 분석]
- 넓고 높은 칸(1필드, 2필드 등)에서 위쪽 절반에 심박과 보조값, 아래쪽 절반에 히스토그램을 표시합니다.
- 기록이 10분을 넘으면 존별 시간 분포를 8가지 TID 모델과 비교해 가장 닮은 형태를 심박 바로 아래에 표시합니다.
  예) HVLI(92%) - 저강도 고볼륨
- 괄호 안 숫자는 내 분포와 모델 분포가 겹치는 정도(%)입니다.
- 8가지 모델: HVLI 저강도 고볼륨, HIT 고강도 인터벌, PRMD 피라미드, R.PRMD 역피라미드, THRD 역치, POL 양극화, R.POL 역양극화, EVEN 균등
- 분석은 넓고 높은 칸에서만 10초마다 하므로 다른 칸에서는 배터리를 쓰지 않습니다. 설정에서 끌 수 있습니다.

[색상 표시]
- 보조값(평균 등)보다 기준(%) 이상 높거나 낮으면 현재 심박의 색을 바꿉니다. 높을 때와 낮을 때 색을 따로 고를 수 있습니다.
- "심박존 색"을 고르면 현재 심박을 항상 존 색으로 표시합니다.
- 배경색은 기기 설정(흰색 / 검정)을 따릅니다.

[심박존 계산]
- 기본은 기기에 설정된 사용자 심박존(현재 스포츠 프로필)을 사용합니다.
- 최대 심박수로 계산: 기본, Joe Friel, Andrew Coggan, USA Cycling, British Cycling, Strava, Garmin 방식
- 1존부터 5존까지 직접 입력할 수도 있습니다.

[칸 크기에 맞춘 자동 배치]
- 10칸 레이아웃의 한 칸: 위쪽에 하트, 존 번호, 보조값, 아래쪽에 현재 심박을 크게 표시합니다.
- 가로로 넓은 칸: 위쪽에 zzHeartPlus 제목과 표시 중인 값(AVG / MAX / LAP), 아래쪽에 두 값을 같은 크기로 나란히 표시합니다.
- 넓고 높은 칸: 운동 형태 분석 화면 (설정에서 끄면 넓은 칸 화면)
- zzSpeedPlus, zzCadencePlus와 같은 글꼴, 같은 크기, 같은 배치를 사용해 함께 쓰면 화면이 일관되게 보입니다.

[기록]
- 현재 심박존을 활동 기록에 함께 저장해 Garmin Connect에서 그래프로 볼 수 있습니다.
- 존별 시간 비율(%)을 활동 요약에 저장합니다.

[지원 기기]
Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060

설정은 Garmin Connect IQ 앱 또는 Garmin Express에서 변경할 수 있습니다.
